# SNN-corrs

Here I'm using spiking neural network models (SNNs) as a playground for exploring the stimulus dependence of noise correlations, for an in-progress paper. The code builds on some lab code for building SNNs (in a private lab repo) from former undergrad Tarek Jabri (at the time of writing 2026, now a PhD student at Harvard), for [his 2022 paper](https://direct.mit.edu/neco/article/34/12/2347/113359/Large-Scale-Algorithmic-Search-Identifies). This project has also been a way for me to gain some experience with AI tools for coding---most of the actual code has been written with Claude Code (Opus 4.5-4.7).

The code is a bit messy right now, as I'm still regularly changing things. The core network functionality is in `fastSNN_fastparallel.py`, which I run parameter sweeps over using `run_sweep.py`. The core logic for building the connectivity matrices and input for the network is in `ConnMatGenerator.py` and `input_generation.py`. Then there are a whole host of analysis scripts which I'll get to documenting when the useful ones have been identified.
